# Agent Commons v0.5.4 — Installer et gérer depuis le navigateur

## Améliorations

- **Actions directement sur les cartes** : prévisualiser l'installation ou la mise à jour d'un skill et choisir les agents destinataires d'un skill installé.
- **Filtres de gestion** : installations gérées, mises à jour du catalogue vérifié, éléments à vérifier et outils locaux/non gérés, avec réinitialisation des filtres.
- **Synchronisation ciblée d'un skill** : sélection explicite des agents installés, simulation puis confirmation avec un jeton à usage unique lié à la sélection, aux fichiers et au plan. Les autres skills, les profils enregistrés et les paramètres MCP sont conservés.
- **Parcours MCP plus lisible** : installation du package, configuration centrale et détection dans les clients sont distinguées. La fiche se rouvre après installation ou configuration pour proposer la suite.
- **Aperçus annulables** : une réponse tardive après fermeture ou navigation ne rouvre plus de confirmation. Les erreurs restent visibles et aucune modification n'est appliquée par une simple prévisualisation.
- Actions de gestion placées avant l'aide, informations auteur/licence sur les cartes, traduction française complétée et filtres mobiles plus compacts.

## Garde-fous et limites

L'interface reste exclusivement locale sur `127.0.0.1`, sans télémétrie ni synchronisation automatique. Chaque modification nécessite un aperçu et une confirmation. Les clients qui lisent directement la bibliothèque centrale voient déjà tous ses skills : la sélection ne les masque pas et ne crée pas de lien supplémentaire. Un MCP détecté dans un client n'est pas une preuve de synchronisation ni de fonctionnement. Désinstaller un package MCP conserve les configurations natives existantes.

L'archive Windows portable inclut son runtime Node.js ; aucun droit administrateur n'est requis. Le ZIP n'est pas signé numériquement. Cette release GitHub ne vaut pas publication npm.

## English summary

v0.5.4 makes the local catalog easier to operate: direct skill install/update previews, managed/update/attention/local filters, per-skill agent selection and a clearer MCP setup path. Targeted skill sync uses a one-use token bound to the selected agents, filesystem revision and preview plan; saved profiles and MCP settings are preserved. Cancelled or outdated preview responses cannot reopen a confirmation. Management actions precede help, source/license metadata is visible, French strings are completed and mobile filters are more compact.

The dashboard remains loopback-only. Native shared-library readers already see all shared skills and need no redundant link. MCP client detection does not prove synchronization or runtime health. The Windows portable ZIP is unsigned; GitHub distribution does not imply npm publication.

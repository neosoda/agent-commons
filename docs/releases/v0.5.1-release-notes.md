# Agent Commons v0.5.1 — Compatibilité multi-IA vérifiée

> Version GitHub pour Windows, Linux et macOS. Gestion locale, sans télémétrie et sans publication npm.

## Nouveautés

- **Bibliothèque partagée native.** Codex, Gemini CLI, Cursor, OpenCode et Windsurf lisent eux-mêmes `~/.agents/skills` (vérifié dans leur documentation officielle). Agent Commons ne crée plus de liens en double dans leurs dossiers et `sync` retire les liens redondants, avec snapshot de restauration. Sur un vrai poste, Gemini CLI affichait un avertissement « Skill conflict » par skill à cause de ces doublons.
- **Nouveaux clients :** Windsurf (skills + MCP), GitHub Copilot CLI (skills + MCP au format `mcp-config.json` avec `type` et `tools`), Qwen Code (skills + MCP). 21 environnements reconnus.
- **Antigravity** : libellés corrigés (`~/.gemini/config` = Antigravity actuel ; `~/.gemini/antigravity` = chemins historiques de l'IDE).
- **OpenCode** : dossier de skills global corrigé (`~/.config/opencode/skills`).
- **`doctor`** : coût en tokens réel pour les clients qui lisent toute la bibliothèque, liens redondants, collisions de noms de skills (deux dossiers déclarant le même `name`), et un dossier de skills lié à la bibliothèque centrale n'est plus signalé comme erreur.
- **Skill Hub** : l'éditeur de profils indique quand un agent voit déjà toute la bibliothèque.

## Tests réels (Windows 11)

Claude Code, Codex, Gemini CLI 0.68, OpenCode 1.19, GitHub Copilot CLI 1.0 et Qwen Code 0.28 lancés contre une configuration synchronisée dans un profil isolé : skills découverts et serveur MCP de démonstration connecté pour chacun (Gemini CLI exige que le dossier de travail soit marqué « trusted »). Cursor, Windsurf, Antigravity et Kiro : chemins vérifiés dans la documentation, pas de test d'exécution.

## Limites

- Pour les clients à bibliothèque native, un profil par agent ne peut pas masquer un skill central.
- Un client plus ancien qui ne lirait pas encore `~/.agents/skills` ne verrait plus les skills après `sync` : restaurer le snapshot `pre-sync` ou mettre le client à jour.
- Archive Windows non signée ; pas de publication npm.

## English summary

v0.5.1 makes skills and MCP work cleanly across AI clients. Codex, Gemini CLI, Cursor, OpenCode and Windsurf natively read `~/.agents/skills`, so Agent Commons stops creating duplicate per-client links (which made Gemini CLI print one conflict warning per skill) and `sync` removes redundant ones with a restorable snapshot. Adds Windsurf, GitHub Copilot CLI (typed `mcp-config.json` entries) and Qwen Code; fixes the OpenCode global skills path and Antigravity labels; `doctor` reports real per-client token cost, redundant links and duplicate skill names. Real runs on Windows 11 with Claude Code, Codex, Gemini CLI, OpenCode, Copilot CLI and Qwen Code discovered the synced skills and connected to the demo MCP server.

- Real hardware acceptance (Windows 11 + LM Studio + verified `tool_calls` model + RTX 5070 Ti) is **not** completed yet.
- The Windows portable ZIP is **unsigned**; SmartScreen, NVDA, and VoiceOver acceptance are not claimed.

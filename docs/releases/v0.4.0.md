## Installation Windows portable

Téléchargez le ZIP et son fichier `.sha256` **depuis la release officielle** puis vérifiez l'empreinte. Dans PowerShell :

```powershell
$zip = ".\AgentCommons-win-x64-portable.zip"
$expected = (Get-Content "$zip.sha256" -Raw).Trim().Split(' ')[0].ToLowerInvariant()
$actual = (Get-FileHash $zip -Algorithm SHA256).Hash.ToLowerInvariant()
if ($actual -ne $expected) { throw "Checksum invalide : abandon." }
```

Extrayez ensuite le ZIP entier, puis exécutez `AgentCommonsPortable\Start-AgentCommons.cmd`. Le navigateur doit pointer sur `127.0.0.1`. Ne jamais exposer le Skill Hub via proxy ou tunnel public.

## Périmètre et limites

La release inclut LM Studio natif, MCP Control Center, catalogue de huit références, profils prédéfinis et personnalisés, synchronisation sélective avec aperçu/validation et sauvegarde/restauration. Les packages MCP tiers ne sont **pas** installés automatiquement et les profils ne désactivent pas les serveurs natifs déjà activés dans les clients.

Cette version est **publiée sur GitHub uniquement**, pas sur npm. L'archive Windows n'est pas signée. Les contrôles automatisés portent sur des environnements synthétiques ; les essais sur un PC Windows physique, NVDA et VoiceOver ne sont pas déclarés réussis.

Les tags et fichiers d'une release publiée sont immuables : toute correction doit utiliser une **nouvelle version**, jamais déplacer `v0.4.0`.

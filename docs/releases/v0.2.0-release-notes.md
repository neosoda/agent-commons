# Agent Commons v0.2.0 — Local Skill Hub

Agent Commons is a local-first hub for sharing AI-agent skills and MCP configuration. v0.2.0 introduces a browser dashboard, an initial guarded MCP editor and a portable Windows distribution.

## Highlights

- **Skill Hub Web** at `127.0.0.1:4173`: discover and search the pinned public skill catalog, inspect installed skill status, manage agent profiles and preview synchronization.
- **MCP server editor**: add stdio/HTTP/SSE definitions, configure per-agent routing and safely remove entries. Existing credentials remain hidden and writes require revision-checked previews and recovery snapshots.
- **Safety and recovery**: integrity checks, explicit confirmations, transactional/atomic configuration handling, manual snapshots, restoration and local-only HTTP protections (Host/Origin/CSRF/CSP).
- **Windows x64 portable ZIP**: bundled SHA-256-verified official Node 24 LTS runtime, no separate Node installation or administrator rights required. Archive and checksum are uploaded as release assets.
- **Quality gates**: Windows, Ubuntu and macOS with Node 22 and 24; real Chromium browser QA at five screen sizes; dedicated Windows launch-and-HTTP smoke test.

## Download and start

**Windows:** download both `AgentCommons-win-x64-portable.zip` and its `.sha256` file from the Assets section, verify the checksum, extract the ZIP, then double-click `AgentCommonsPortable/Start-AgentCommons.cmd`.

**Other operating systems / source:**

```bash
git clone https://github.com/neosoda/agent-commons.git
cd agent-commons
npm ci && npm run build
node dist/cli/index.js web
```

The browser interface is restricted to the local machine. No agent configuration or third-party skill is synchronized or installed automatically.

## Scope and limitations

- MCP editing is deliberately limited for **existing** servers: sensitive commands/URLs/credentials and custom overrides are preserved and must be modified through the central manifest.
- The Windows portable package is **not code-signed**. Verify the supplied checksum and download only from this repository's official GitHub Release.
- npm distribution `@neosoda/agent-commons` depends on the npm Trusted Publisher configuration. A successful GitHub Release does not by itself guarantee npm availability.
- Read the [README](https://github.com/neosoda/agent-commons#readme), [security policy](https://github.com/neosoda/agent-commons/blob/main/SECURITY.md) and [changelog](https://github.com/neosoda/agent-commons/blob/main/CHANGELOG.md) before operating on live agent configurations.

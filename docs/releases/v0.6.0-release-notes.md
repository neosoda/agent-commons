# Agent Commons v0.6.0 — Moteur IA local expérimental et nouvelle interface

Cette version ajoute un **premier moteur de missions IA local-first**, indépendant de la gestion des skills et MCP, et une refonte complète de l'interface locale **Operating Surface**.

## Nouveautés

- **LM Studio :** exécution de missions bornées avec un modèle local capable d'appels d'outils ; lecture Git et modifications sur autorisation.
- **Anti-boucle :** arrêt sur répétition, stagnation et retour A → B → A d'une version de fichier.
- **Reprise :** checkpoints liés à un dépôt exact ; budgets de tokens, étapes, outils et appels cloud.
- **Cloud facultatif :** escalade bornée, jamais de partage de code implicite.
- **Operating Surface :** interface locale modernisée, thème clair/sombre et recherche clavier Ctrl+K / ⌘K / /.
- **Catalogue :** Motion Educator et six sélections Hermes opt-in, sans installation automatique.

## Essai (depuis les sources)

Après `npm ci` puis `npm run build`, charger un modèle avec outils dans LM Studio et lancer :

```powershell
node dist/runtime/cli.js --workspace "A:\PROJETS\MON-DEPOT" --task "Inspecte ce projet" --model "ID_MODELE_LM_STUDIO"
```

Les options `--allow-write` et `--allow-tests` doivent être données expressément, uniquement pour une branche de test d'un dépôt fiable. Voir [la documentation](../LOCAL_AGENT_RUNTIME.md).

## Limites et sécurité

Le moteur reste **expérimental** : MCP non exécutés dans la boucle, pas de sandbox OS, de daemon permanent, de dashboard missions ni de benchmark réel RTX 5070 Ti. Les tests automatisés n'établissent pas l'intelligence du modèle. L'interface locale non authentifiée reste strictement sur `127.0.0.1`, sans exposition Internet.

Archive Windows portable avec checksum SHA-256, non signée. **Release GitHub uniquement : aucune publication npm revendiquée.**

## English summary

v0.6.0 introduces an **experimental local-first mission runner** for LM Studio-compatible models, Git workspaces, explicit edit/test approval, bounded anti-loop execution and workspace-bound checkpoints. It also ships the redesigned Operating Surface UI and opt-in curated Motion Educator/Hermes entries. Still missing: MCP execution inside missions, an OS sandbox, 24/7 autonomy, mission dashboard and real RTX 5070 Ti benchmarks. Windows ZIP is unsigned; npm publishing remains separate.

# Agent Commons v0.3.0 — A local Skill Hub ready to share

**A safer, more polished release for people managing AI coding agents on their own machines.**

Agent Commons brings a common skills library, curated public skill references, agent-specific profiles and MCP routing into one **local-only** dashboard. It supports 17 registered agent environments and provides explicit preview, confirmation and recovery operations.

## What's new since v0.2.0

- **French + English Skill Hub**, with a locally saved language choice and clearer feedback on operations.
- **Accessible interactions:** keyboard navigation, skip link, visible focus, focus-trapped dialogs, error announcements, improved contrast and responsive Chromium-tested screens.
- **More reliable editing:** unsaved profile selections survive refreshes; obsolete server responses cannot overwrite newer UI state; pending actions cannot be submitted twice.
- **Safer MCP workflows:** failed previews retain entered configuration, provide an inline error and can be retried. Synchronization previews discarded after navigation cannot unexpectedly reopen confirmation dialogs.
- **Improved backup and restore safety:** recursive content preflight, staging on destination volumes, rollback recovery preservation and stronger tests for concurrent changes and partial failures.
- **Stricter HTTP privacy:** unexpected backend errors never reveal arbitrary exception details to the browser.
- **Correct CLI version reporting:** `agent-commons --version` uses installed package metadata, not a stale string.
- **Stronger Windows distribution tests:** the built ZIP is re-extracted into a fresh location and exercised with its embedded Node runtime, an isolated home, local HTTP boot, version checks and SHA-256 verification.

## Download and start on Windows 10/11 x64

1. Download **AgentCommons-win-x64-portable.zip** and its matching **.sha256** from this GitHub Release.
2. Verify the ZIP's checksum, then extract the **entire** ZIP into a writable folder.
3. Open **AgentCommonsPortable/Start-AgentCommons.cmd**.
4. Use the local dashboard at **http://127.0.0.1:4173**. Stop with **Ctrl+C** in the console.

No separate Node.js installation, Docker or administrator rights required. The ZIP is **not code-signed**; verify the SHA-256 published with it.

For Linux/macOS and developers, see [Quick start](https://github.com/neosoda/agent-commons#quick-start) (Node.js 22+ and Git).

## Safety and known limitations

- The dashboard runs on **127.0.0.1 only** and has **no login**. **Do not expose it to the internet or a LAN**, or place it behind a tunnel/proxy.
- Synchronization, installing skills and restoring snapshots are **explicit, potentially mutating actions**. Preview and back up before applying changes.
- Public skill metadata and licence review do **not** certify third-party code as safe.
- Advanced editing of existing MCP server commands, URLs and environment references remains deliberately limited to preserve private values. Existing server routing is editable.
- Automatic regression checks cover Windows, macOS and Linux (Node.js 22/24), Chromium in a synthetic environment, and Windows ZIP extraction/boot. They do **not** replace a manual installation on a separate physical Windows machine, NVDA/VoiceOver assessment or code-signing certification.
- The npm package `@neosoda/agent-commons` is **not an assured distribution channel** until an authorized package owner has bootstrapped it and verified availability in the npm registry. Prefer this Release's Windows ZIP or a source checkout.

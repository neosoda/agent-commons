# Agent Commons v0.5.0 — Extension Manager et diagnostics Windows réels

> **Version GitHub pour Windows, Linux et macOS.** Gestion locale, sans télémétrie et sans publication npm. Le Skill Hub reste strictement sur `127.0.0.1`.

## Nouveautés

- **Extension Manager** (Skill Hub) : installation isolée, réparation, mise à jour vers la version revue et désinstallation des paquets MCP revus (Playwright et Filesystem via npm, Fetch et Git via uv), avec aperçu, confirmation et retour arrière. Configuration guidée pour des clients choisis, puis synchronisation ciblée séparée.
- **`doctor` enrichi (lecture seule)** : prérequis sur le PATH, vérification que les exécutables et scripts de chaque serveur MCP (manifeste central et clients) existent, détection des `SKILL.md` que les clients refusent, estimation du coût en tokens des skills par agent.
- **`mcp probe`** : démarre explicitement un serveur MCP, vérifie `initialize` + `tools/list`, peut effectuer un appel d'outil (`--arg clé=valeur`), puis arrête le processus. Les serveurs HTTP qui exigent des identifiants sont signalés « non vérifiés ».
- **`mcp demo-config`** : serveur MCP de démonstration sans dépendance ni secret pour tester un client de bout en bout.
- **Skill Hub** : diagnostics affichant les MCP qui ne peuvent pas démarrer et les skills invalides (sans chemins ni secrets) ; avertissement avant de désinstaller un paquet encore référencé.
- **Catalogue Skills & MCP interactif** unifié dans le Skill Hub (recherche, filtres, statuts, prompts d'exemple).
- **Agent Desktop** (Vercel Labs) : skill et référence MCP de contrôle du bureau, strictement opt-in, profil `desktop-control` isolé des outils Web/OSINT.
- Nouvelles références épinglées du catalogue (201 skills) : **Grim Prompter** (modélisation des menaces), **SaaS Product Demo Video v2**, **Video Engine** et **Remotion Superpowers**, shadcn **Improve**.

## Corrections Windows (audit sur un vrai poste)

- Installation des MCP gérés impossible depuis un dossier utilisateur profond (répertoire de travail > 260 caractères).
- Restauration, installation de skills et réparation centrale en échec au-delà de 260 caractères (`mkdtemp` sans préfixe long).
- Tests en échec sur un compte Windows standard (sans mode développeur).
- Arguments JSON mal transmis depuis Windows PowerShell 5.1.
- Statuts MCP ambigus dans l'interface.
- Construction de l'archive portable en échec sous Windows PowerShell 5.1 (`Invoke-WebRequest` sans `-UseBasicParsing`) ; ses tests utilisent désormais un profil synthétique.

## Installer / mettre à jour

**Windows (sans Node.js)** : télécharger `AgentCommons-win-x64-portable.zip` **et** `AgentCommons-win-x64-portable.zip.sha256` depuis les assets ci-dessous, vérifier l'empreinte SHA-256, extraire l'archive complète puis démarrer `AgentCommonsPortable/Start-AgentCommons.cmd`.

**Linux / macOS / Windows avec Node.js 22+** : code source de cette release, `npm ci`, `npm run build`, puis `node dist/cli/index.js doctor` et `node dist/cli/index.js web`. Le paquet npm n'est **pas** publié.

## Limites connues

- Désinstaller un paquet MCP ne retire pas les entrées des clients ; l'aperçu les liste.
- Pas de vérification en ligne des nouvelles versions amont ; seules les versions revues sont proposées.
- `mcp probe` exécute la commande configurée : à utiliser seulement pour des serveurs de confiance. Il n'existe qu'en ligne de commande.
- Archive Windows non signée ; NVDA/VoiceOver, SmartScreen, Gemini CLI, LM Studio et OpenCode non testés en conditions réelles.

## English summary

v0.5.0 adds the unified interactive Skills & MCP catalog, the opt-in Agent Desktop skill/MCP, new pinned catalog references (Grim Prompter, SaaS Product Demo Video v2, Video Engine, Remotion Superpowers, shadcn Improve; 201 skills), and ships the reviewed MCP **Extension Manager** (isolated pinned npm/uv packages with preview, repair, update, uninstall and targeted client provisioning) and real-world diagnostics: a read-only `doctor` that checks prerequisites, MCP launch targets and `SKILL.md` metadata and estimates per-agent skill token cost; an explicit `mcp probe` that performs a real MCP handshake and optional tool call; and a secret-free demo MCP server. It fixes Windows failures found on a real machine: deep-path package installs, restore beyond MAX_PATH, standard-account test failures and PowerShell 5.1 argument quoting.

**Not included:** live upstream version checks, removal of native client entries on package uninstall, npm publication, Windows code signing.

# Agent Commons v0.5.2 — Nettoyage ciblé des doublons

> Version GitHub pour Windows, Linux et macOS. Gestion locale, sans télémétrie et sans publication npm.

## Corrections

- **Conseil de `doctor` ciblé.** Pour retirer les liens en double, `doctor` proposait `agent-commons sync --skills-only`. Sur un vrai poste, cette commande aurait aussi lié les 96 skills centraux manquants dans Claude Code et Antigravity, soit environ 8 000 tokens de plus par session. Le conseil cible désormais uniquement les clients concernés, par exemple `agent-commons sync --skills-only --agent codex --agent gemini-cli`, avec aperçu via `--dry-run`.
- **Dossier de skills lié à la bibliothèque centrale.** Quand le dossier de skills d'un client est lui-même un lien vers `~/.agents/skills` (cas fréquent pour Antigravity), `sync` l'indique comme « déjà partagé » au lieu d'un conflit.

## Validé sur un vrai poste Windows 11

287 liens redondants retirés de `~/.codex/skills` et `~/.gemini/skills` avec la commande ciblée (snapshot `pre-sync` créé). Codex voit toujours ses 349 skills, sans aucune erreur de chargement.

## Limites

Inchangées depuis v0.5.1 : pour les clients qui lisent `~/.agents/skills`, un profil par agent ne peut pas masquer un skill central ; archive Windows non signée ; pas de publication npm.

---

## English summary

v0.5.2 makes duplicate-link cleanup safe. `doctor` now recommends `sync --skills-only --agent <affected clients>` instead of a plain skills sync, which would also have linked every missing central skill into clients such as Claude Code (about 8k extra tokens per session on the audited PC). A client skills folder that is itself a link to `~/.agents/skills` is reported as already shared rather than as a conflict. Validated on a real Windows 11 profile: 287 redundant links removed, Codex still lists all 349 skills with no load error.

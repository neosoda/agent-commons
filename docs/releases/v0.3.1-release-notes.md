# Agent Commons v0.3.1 — Safety and release maintenance patch

This patch includes post-v0.3.0 reliability fixes and the completed P2 release-hygiene work.

## Highlights

- **Sync approvals now match the reviewed state.** Preview a saved-profile or
  full skills+MCP synchronization, then explicitly approve the same short-lived,
  one-time operation. If the managed profiles, skills, MCP manifest or agent
  files changed after the preview, the server **refuses** and asks for a new
  preview rather than silently applying a different plan.
- **Safer profile editing.** Changing the selected agent while an asynchronous
  save is in progress no longer targets the wrong profile or discards another
  agent's unsaved selections. Duplicate saves remain blocked during the request.
- **More realistic security guidance.** The supported release policy, local-only
  dashboard restrictions, user-triggered GitHub downloads and backup limitations
  are documented accurately.
- **Cleaner CI.** Retired the one-shot v0.3.0 publisher after its successful
  release; regular CI, Chromium, Windows ZIP and future manual release assets
  workflows remain in place.
- **Manual acceptance kit.** A PowerShell verifier checks the ZIP downloaded
  from GitHub, its SHA-256, embedded Node/CLI, extracted path with spaces and
  local HTTP startup under a disposable synthetic home. A Windows/NVDA/VoiceOver
  test checklist is available in `docs/qa/RELEASE_ACCEPTANCE.md`.

## Windows download

Download **AgentCommons-win-x64-portable.zip** and its adjacent **.sha256** from
this release. Validate the checksum, extract the complete archive, then open
`AgentCommonsPortable/Start-AgentCommons.cmd`. No separate Node installation,
administrator account or Docker required. The ZIP is unsigned.

## Safety and limitations

The dashboard listens only on **127.0.0.1** and has no login: do **not** expose
it on a network, proxy or tunnel. All writes remain explicit. The new revision
guard provides optimistic concurrency detection but is not a guarantee against
every power failure or external filesystem race.

CI covers six OS/Node combinations, real Chromium and a Windows ZIP extracted
and smoke-tested on a runner. This **does not** certify an independent physical
Windows/SmartScreen installation or NVDA/VoiceOver screen-reader use.

The npm package remains a separate, account-authorized distribution channel:
do not assume `npx @neosoda/agent-commons` is available until the registry
confirms publication.

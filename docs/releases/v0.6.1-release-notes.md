# Agent Commons v0.6.1 — Correctif de sécurité Windows et fiabilité du moteur de missions

Cette version livre les correctifs et ajouts fusionnés dans `main` depuis la v0.6.0. **Mise à jour recommandée** pour tout utilisateur du moteur de missions sous Windows.

## Sécurité

- **Alias Windows 8.3 :** sur un volume NTFS avec noms courts, `GIT~1` ou `ENV~1` contournaient la protection des chemins du moteur de missions. Une mission autorisée à écrire (`--allow-write`) pouvait créer `.git/hooks/pre-commit` (exécuté au commit suivant) ou lire `.env`. Les chemins sont désormais revérifiés sous leur forme canonique ; les noms finissant par un point ou un espace sont refusés ; les erreurs ne transmettent plus de chemins absolus.
- **Interruption des outils :** une perte de bail ou un `--cancel` / `--pause` pendant un outil interrompt l'outil et son arbre de processus ; une pause demandée pendant la réponse du modèle est respectée avant l'appel d'outil suivant.
- **Environnement des MCP de mission :** construit par liste blanche ; les clés et jetons `AGENT_COMMONS_*` ne sont plus transmis aux serveurs MCP.
- **Racines XERJ :** les dossiers protégés (home, `.agents`, sauvegardes) sont comparés sous forme canonique et sans casse sous Windows.

## Nouveautés

- **Mission Control** indique si le worker local tourne, avec la commande pour le lancer.
- **Références optionnelles :** recherche locale XERJ (binaire épinglé), MCP externe Sellbird (installation manuelle, risque critique), bibliothèque Claude SEO, skills `universal-product-engineering` et `ux-psychology`, SimuLab. Aucune n'est installée automatiquement.
- **Maintenance :** drain transactionnel du worker avant un redéploiement.

## Corrections

- Les missions ne chargent plus de skills sans rapport avec la tâche ; la reprise d'une mission conserve ses protections anti-boucle.
- 20 descriptions du catalogue réparées depuis le texte amont épinglé, avec leurs phrases « Use when… » utilisées par le routeur.
- Skill Hub : accueil plus compact et statuts factuels (« agents détectés », « non vérifié »), agents absents repliés, page Missions traduite en français.

Détail complet : [CHANGELOG](../../CHANGELOG.md).

## Limites

Le moteur de missions reste **expérimental** : pas de sandbox OS. Accorder à la fois `--allow-write` et `--allow-tests` permet au modèle d'exécuter du code ; ne le faire que dans un worktree jetable. Aucune recette complète LM Studio / RTX 5070 Ti n'est revendiquée. Archive Windows portable avec checksum SHA-256, **non signée**. **Release GitHub uniquement : aucune publication npm.**

## English summary

v0.6.1 ships everything merged since v0.6.0. **Security:** on NTFS volumes with 8.3 short names, `GIT~1` / `ENV~1` bypassed the mission runtime's protected paths, so a mission with `--allow-write` could plant `.git/hooks/pre-commit` or read `.env`; paths are now re-checked in canonical form. Running tools are interrupted on lost lease, cancel or pause; mission MCP servers get an allowlisted environment without provider credentials; XERJ roots are compared canonically. **Added:** worker status in Mission Control, optional XERJ / Sellbird / Claude SEO / SimuLab references and two original skills, a transactional maintenance drain. **Fixed:** topical-only mission skill selection, resume safeguards, 20 catalog summaries, honest Skill Hub statuses and French Missions page. The runtime is still experimental with no OS sandbox; the Windows ZIP is unsigned; no npm publication.

# Agent Commons v0.4.0 — MCP Control Center

> **Version GitHub pour Windows, Linux et macOS.** Gestion locale, sans télémétrie et sans publication npm. Le Skill Hub reste strictement sur `127.0.0.1`.

## Nouveautés

- **LM Studio natif** sur Windows, Linux et macOS : reconnaissance de `~/.lmstudio/mcp.json`, lecture des noms de serveurs, fusion sans effacer les MCP préexistants. Aucun faux dossier de skills n'est créé.
- **MCP Control Center** dans le Skill Hub, avec interface bilingue FR/EN : catalogue de huit références MCP, inventaire des clients, état des configurations, profils et synchronisation sélective.
- **Profils MCP** OSINT, Développement et Infrastructure, plus profils personnalisés par client. Séparation de l'OSINT non fiable et de Docker sensible dans les profils.
- **Sécurité et récupération :** aperçu avant application, jeton de confirmation à usage unique lié à la révision, prévention des conflits, sauvegardes/restauration des configurations MCP **et** des profils personnalisés. Aucun serveur tiers n'est exécuté par simple consultation du catalogue.
- **Windows portable** : bundle vérifié avec Node.js embarqué, contrôles sur `HOME` synthétique et choix d'un port loopback réellement disponible.
- Maintien des fonctions existantes, dont le **Smart Skill Router** qui choisit les métadonnées de skills sans charger leur contenu inutilement.

## Installer / mettre à jour

**Windows (sans Node.js)** : télécharger `AgentCommons-win-x64-portable.zip` **et** `AgentCommons-win-x64-portable.zip.sha256` depuis les assets ci-dessous, vérifier l'empreinte SHA-256, extraire l'archive complète puis démarrer `AgentCommonsPortable/Start-AgentCommons.cmd`. N'exposez jamais le Skill Hub par un tunnel ou un proxy.

**Linux / macOS / Windows avec Node.js 22+** : utiliser le code source de cette release, `npm ci`, `npm run build`, puis `node dist/cli/index.js web`. Le paquet `@neosoda/agent-commons` **n'est pas annoncé comme publié sur npm**.

## Limites connues

- Le catalogue **n'installe, ne met à jour ni ne désinstalle automatiquement** les packages MCP. Web Search et OSINT attendent un fournisseur effectivement vérifié.
- Un profil limite **les ajouts gérés par Agent Commons**, mais ne désactive **pas** les MCP déjà activés dans chaque client. Restreindre les chemins filesystem et les droits Docker au niveau des serveurs eux-mêmes.
- Import global automatique et diagnostics de lancement réels non inclus. Les tests CI utilisent des environnements synthétiques, pas les fichiers MCP privés de l'utilisateur.
- Archive Windows **non signée** ; aucun test matériel Windows ni certification NVDA/VoiceOver revendiqués.

## English summary

Agent Commons v0.4.0 adds native LM Studio MCP file support; an offline eight-server MCP reference catalog; an integrated bilingual MCP Control Center; per-client OSINT, Development, Infrastructure and custom profiles; selective non-destructive synchronization, one-time preview approval and recoverable snapshots. Windows portable packaging is verified with an embedded Node.js runtime and matching SHA-256.

**Not included:** automatic installation/update/removal of third-party MCP servers, full native-config import, live launch diagnostics or automatic disabling of pre-existing client MCP tools. The local-only Skill Hub must **never** be publicly exposed. GitHub-only release; no npm publication or Windows code signing.

# UX Psychology — an actionable 30-principle UX skill

`ux-psychology` applies the [30 topics listed by Laws of UX](https://lawsofux.com/fr/laws/) to UI audits, redesign and implementation: task flows, information hierarchy, accessible interactions, forms, dashboards, feedback, errors and QA.

Independent original skill inspired by Jon Yablonski's Laws of UX (the French site's translator is credited as Lionel Nolhac); **not official or endorsed**. No external illustrations or article bodies are copied. Credits: `skills/ux-psychology/references/sources.md`.

The catalog contains a **pinned Git commit**; installation is opt-in after preview/approval. The router returns metadata only, the small `SKILL.md` is loaded explicitly, and detailed references load selectively. No scripts, new MCP server, automatic agent sync or native prompt injection.

```bash
agent-commons catalog search ux-psychology
agent-commons catalog info ux-psychology
agent-commons catalog install ux-psychology
agent-commons skills route "Improve the skill catalog UX" --json
agent-commons skills load ux-psychology --json
agent-commons skills load ux-psychology --resource references/principles.md
```

**Prompt:** “Audit this dashboard with UX Psychology, prioritize five evidence-backed problems, recommend scoped changes, and test the primary keyboard/mobile journey.” Heuristics are not empirical results or WCAG certification.
